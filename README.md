## 常见问题

**海外云服务器需要备案吗？**
不需要。ICP 备案只针对解析到中国大陆服务器的域名，Vultr 这类机房全部在境外的云服务器不涉及备案，开通后绑定域名即可上线，这也是很多人选海外机器的直接原因。

**Vultr 用到一半不想要了，钱能退吗？**
余额不能退，但可以止损：销毁实例后计费立即停止，账单只包含实际使用的小时数。所以正确姿势是控制充值额度，用多少充多少。

**分配的 IP 从大陆打不开怎么办？**
销毁实例重新部署可以免费换 IP。业务需要固定 IP 就买保留 IP（闲置 $3/月），这样换机器 IP 也不变。

**一台机器能装什么系统？**
主流 Linux 发行版（Ubuntu、Debian、AlmaLinux、Rocky 等）、Windows Server、FreeBSD 都能一键安装，还支持上传自定义 ISO 和一键应用镜像（WordPress、Docker 等），root 权限完整保留。

**超出流量的部分怎么收费？**
$0.01/GB，超出 100GB 就是 $1，用量在控制台实时可查。
